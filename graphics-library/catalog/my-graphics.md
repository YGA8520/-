# ספריית הגרפיקה של יענקי

אוסף של כ-10,000 קבצים בתיקייה **D:\גרפיקה** במחשב של יענקי. הסקיל הזה הוא המפתח לאוסף: הוא אומר איפה כל דבר נמצא, איך לבחור, ואיך מעדכנים.
הקטלוג המפורט, קובץ אחרי קובץ, נמצא בשני סקילים נלווים. כדאי לטעון את מה שרלוונטי:
- **my-graphics-frames** — מסגרות דף, מסגרות תמונה, רקעי "מלכות", תבניות אירועים.

עותק של הקטלוג שמור גם במחשב: `D:\גרפיקה\_קטלוג\`.

## 2. כללי איכות
- **רזולוציה:** להדפסה צריך בערך 300dpi, כלומר A4 ≈ 2480×3508 ו-A5 ≈ 1748×2480. אם הקובץ קטן מזה, מודיעים ליענקי או מחפשים חלופה. בקטלוג מצוין הגודל של כל קובץ.
- **שקיפות:** אלמנט שמונח מעל רקע צריך להיות קודם כול PNG שקוף (בעיקר מ"אלמנטים פונטייפ"). JPG עם רקע לבן אפשר לשלב רק על רקע לבן, או אחרי הסרת רקע.
- **סימני מים:** רוב ה-JPG ב"רקעים מלכות" נושאים "www.Birkon.co.il", והקבצים ב"אלמנטים" הם תמונות תצוגה קטנות. משתמשים בהם רק להשראה. ל"שער מלכות" יש PSD וגרסאות PNG נקיות.
- **PSD:** אלה מקורות עם שכבות. ImageMagick מוציא את התמונה המשוטחת: `convert "file.psd[0]" -flatten out.png`.
- **WMF** (קליפרט): ממירים כך: `soffice --headless --convert-to png file.wmf`.

## 3. כללי תוכן (מחייבים)
- בעיצוב לא שמים תמונה שבה מופיעות נשים או בנות (מעל גיל 6 בערך). זה נבדק בכל תמונה שיש בה דמויות, בעיקר ב"תמונות יודאיקה" ובתיקיות האנשים, הילדים והמשפחה שב"לבנות לינדר".
- ציורי האמנים ב"תמונות יודאיקה" (פלרובה, טלקו, זסלבסקי) מוגנים בזכויות יוצרים. בעיצוב שיפורסם ברבים מזכירים את זה ליענקי.

## 4. איך מגיעים לקבצים
- **בצ'אט, כשאפליקציית Claude שולחנית מחוברת למחשב:**
  `device_list_dir("D:\\גרפיקה\\<תיקייה>")` כדי לראות מה יש, ו-`device_stage_files([...])` כדי להעתיק קבצים (עד 50 בקריאה). הקבצים מגיעים אל `/mnt/user-data/uploads/גרפיקה/<תיקייה>/<קובץ>`.
  אם התיקייה לא מחוברת לשיחה: `device_request_folder_access(["D:\\גרפיקה"])`.
  ייתכן ש-device_bash לא יצליח לעגן את התיקייה. במקרה כזה עובדים רק עם list ו-stage.
- **ב-Claude Code שרץ על המחשב של יענקי:** קוראים ישירות מ-`D:\גרפיקה\` (או מ-`/mnt/d/גרפיקה/` ב-WSL).
- **ב-Claude Code בענן או בלי גישה למחשב:** אין גישה לקבצים המקוריים. בוחרים לפי הקטלוג, ואז אומרים ליענקי בדיוק אילו קבצים לצרף (נתיב מלא). אם יש בריפו שלו (YGA8520/-) תיקיית `graphics-library/`, משתמשים בה.

## 5. בחירה מתוך ספרייה גדולה (גיליון תמונות מוקטנות)
בתיקיות הגדולות (יודאיקה, נופים, לבנות לינדר, קליפרט) לא בוחרים לפי שם קובץ. התהליך:
1. מצמצמים לתת-תיקייה לפי הקטלוג, ומוציאים רשימת קבצים בעזרת device_list_dir.
2. מעתיקים עד כ-30 מועמדים ל-uploads (קבצים קטנים קודם).
3. מכינים גיליון ממוספר ומסתכלים בו בעזרת Read:
```python
# usage: python3 sheet.py OUT.jpg file1 file2 ...
import sys; from PIL import Image, ImageDraw; Image.MAX_IMAGE_PIXELS=None
out,fs=sys.argv[1],sys.argv[2:]; T=220; C=6; R=(len(fs)+C-1)//C
s=Image.new('RGB',(C*T,R*T),'white'); d=ImageDraw.Draw(s)
for i,f in enumerate(fs):
    im=Image.open(f); im.draft('RGB',(T*3,T*3)); im=im.convert('RGBA'); im.thumbnail((T-6,T-6))
    x,y=(i%C)*T+3,(i//C)*T+3; s.paste(im,(x,y),im); d.rectangle([x,y,x+28,y+18],fill='black'); d.text((x+3,y+3),str(i),fill='yellow')
s.save(out,quality=82)
```
4. בוחרים, ובודקים שוב את כללי התוכן (סעיף 3).

## 7. עדכון הספרייה (כשיענקי מוסיף גרפיקה)
תיקיית הקליטה: **D:\גרפיקה\_חדש**. יענקי מכניס אליה קבצים ואומר "עדכן את קטלוג הגרפיקה".
1. `device_list_dir("D:\\גרפיקה\\_חדש", recursive=true)`.
2. מעתיקים את הקבצים (עד 50 בקריאה), מכינים גיליון (סעיף 5) ומסתכלים בו.
3. לכל קובץ רושמים: סוג (מסגרת, רקע, אלמנט, עיטור, באנר וכו'), תיאור וסגנון, צבעים, גודל בפיקסלים, האם שקוף, האם יש סימן מים, והאם מופיעות דמויות.
4. מציעים לכל קובץ תיקיית יעד קיימת בקטלוג. את הקבצים מזיזה יענקי עצמו, או Claude Code שרץ על המחשב. אין למחוק את המקור.
5. מעדכנים את הקטלוג בשני המקומות:
   - כותבים את קובץ ה-md המעודכן אל `D:\גרפיקה\_קטלוג\` (בעזרת device_commit_files).
   - מציעים עדכון לסקיל המתאים עם `propose_skills` (kind: improvement, edits): מסגרות ורקעים ל-my-graphics-frames, אלמנטים ל-my-graphics-elements, ותיקייה חדשה או גדולה לסעיף 6 כאן. יענקי שומר את העדכון מהכרטיס, וכך הוא מגיע לכל השיחות ול-Claude Code.
6. על תיקיית תמונות גדולה (מאות קבצים) לא כותבים רשומה לכל קובץ. מוסיפים רשומה ברמת התיקייה, על סמך מדגם של כ-30 קבצים.
