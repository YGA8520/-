# graphics-library — עותק של ספריית הגרפיקה של יענקי

המקור נמצא במחשב של יענקי, בתיקייה `D:\גרפיקה`. כאן יש עותק מוקטן של **התיקיות שימושיות לעיצוב**, כדי שגם Claude Code בענן (בלי גישה למחשב) יוכל לעבוד איתן.

## מה יש כאן
| תיקייה | קבצים |
|---|---|
| מסגרות | 42 |
| תמונת מסגרת 1 | 49 |
| רקעים מלכות | 35 |
| רקעים וכדומה | 67 (בלי הכפילויות של "אלמנטים פונטייפ" ו"תמונת מסגרת 1") |
| רקעים 2 | 7 |
| אלמנטים פונטייפ | 45 (בלי קובצי הגופנים) |
| אלמנטים | 87 |
| וילונות | 16 |
| איורים | 102 |
| רקעי פורמייקה ועץ | 31 |

**מה לא הועלה** (נשאר רק במחשב): ספריות התמונות הגדולות (תמונות יודאיקה, נופים מטורפים, תמונות נוף, לבנות לינדר, קליפרט, עיטורים), התיקייה ישיבה, גופנים, קובצי PSD, וגם `וילונות\וילון (1).jpg`, שלא הצליח לעלות.

## איך הקבצים הוקטנו (`tools/mirror.py`)
- **צלע ארוכה:** לכל היותר 3508px, שזה A4 ב-300dpi. קבצים קטנים יותר נשארו בגודל המקורי.
- **צילומים:** JPG באיכות 85.
- **קבצים שקופים:** נשמרו כ-PNG, והשקיפות נשמרה.
- **BMP ו-GIF:** הומרו ל-PNG. לכן `איורים\01C.BMP` מופיע כאן בשם `איורים/01C.png`.
- **התאמה למקור:** `manifest.json` ממפה כל קובץ כאן לקובץ המקורי במחשב, עם הגודל בפיקסלים ואם הוא שקוף.

השמות זהים לשמות במחשב (רק הסיומת השתנתה, כמתואר למעלה). לכן הקטלוג תקף גם כאן.

## קטלוג
- `catalog/my-graphics.md` — מפתח, כללי בחירה, כללי תוכן ותהליך העדכון.
- `catalog/my-graphics-frames.md` — מסגרות ורקעים, קובץ אחרי קובץ.
- `catalog/my-graphics-elements.md` — אלמנטים, וילונות, איורים ועץ.
- `catalog/large-libraries.md` — הספריות הגדולות, ברמת תיקייה.

אותם קטלוגים נשמרים גם כסקילים בחשבון (my-graphics, my-graphics-frames, my-graphics-elements), ובמחשב בתיקייה `D:\גרפיקה\_קטלוג\`.

## עדכון
כשמוסיפים גרפיקה (דרך `D:\גרפיקה\_חדש`), מעדכנים בכל המקומות: הקטלוג במחשב, הסקילים, ואת התיקייה כאן. מריצים
`python3 graphics-library/tools/mirror.py <עותק מקומי של D:\גרפיקה> graphics-library <תיקייה>`,
מעדכנים את `catalog/`, ועושים commit ו-push.
