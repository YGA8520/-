# מבחני הסימנים – הקובץ המעוצב

הקובץ המקורי (`src/all-tests.pdf`, 102 עמודים) הוקלד מחדש בעיצוב אחיד, ונוספו שער, שער פנימי, קרדיטים, תוכן עניינים (ויומן ציונים), עמודי חלקים ושער אחורי.

**התוצאה:** `output/mivchanei-hasimanim.pdf` (A4, 104 עמודים) · `output/front-pages/` (השער, השער הפנימי, הקרדיטים והשער האחורי כקבצים נפרדים) · `output/דוח-עריכה.pdf` (מה הוסר, מה לאשר, שגיאות כתיב שנשארו).

## איך בונים מחדש
```
./run_all.sh
```
דרישות: python3 (pymupdf, pypdf, pillow, numpy), poppler-utils, node + playwright עם chromium.

## מבנה
| קובץ | תפקיד |
|---|---|
| `tools/extract.py` | חילוץ טקסט מה-PDF בסדר קריאה נכון (המקור יוצא מ-Word בעברית ואחר כך נערך, לכן סדר התווים והרווחים בקובץ לא הגיוניים), יחד עם מיקום וסגנון |
| `design/manifest.py` | רשימת היחידות: אילו עמודים, כותרת, סימן החותם, סדר וחלק. כאן משנים כותרות וסדר. גם רשימת העמודים שהוסרו |
| `tools/parse_units.py` | זיהוי שאלות, תשובות, כותרות ושורות כתיבה → `work/units.json` |
| `design/manual.py` | עמוד אחד (סימן עו) שנבנה ידנית |
| `design/body.py` | עיצוב הגוף (CSS) |
| `design/front.py` | שער, שער פנימי, קרדיטים, חלקים, תוכן עניינים, שער אחורי |
| `build.py` | הרכבה: מספור עמודים באותיות, כותרת עליונה, מסגרת, סימניות ב-PDF |
| `tools/verify.py` | בדיקת נאמנות: כל מילה במקור מופיעה בקובץ החדש ולהפך |

פלטת הצבעים והחותם לקוחים מהלוגו של "ברומו של עולם" (נייבי וזהב). הגופנים הם Frank Ruhl Libre, Suez One, Heebo (רישיון OFL).
