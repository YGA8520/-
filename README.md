# נוסח — משפחת גופנים עבריים

גופן עברי ספרותי־קליגרפי בחמישה משקלים, בהשראת הסגנון הכללי של דפוס עברי כתוב בקולמוס רחב:
קווים אופקיים עבים, גזעים שמתעבים ומתעקלים לרגל מחודדת שפונה שמאלה, קרס יורד בקצה השמאלי
של הקו העליון, כתפיים ימניות מעוגלות וקצוות מחודדים בירידות (ק, ך, ן, ץ).

| משקל | קובץ |
|------|------|
| קל (300) | `Nusach-Light.ttf` |
| רגיל (400) | `Nusach-Regular.ttf` |
| בינוני (500) | `Nusach-Medium.ttf` |
| מודגש (700) | `Nusach-Bold.ttf` |
| שחור (900) | `Nusach-Black.ttf` |

**הורדה:** `Nusach-Hebrew-Fonts.zip` (בשורש הריפו) מכיל את כל הקבצים, קובצי אינטרנט ודף הדגמה.
דף ההדגמה: `specimen/Nusach-specimen.png` ו-`specimen/Nusach-specimen.pdf`.

## מה זה, ומה זה לא

הגופן הוא **עיצוב מקורי** שנוצר מאפס. הוא נוצר בהשראת הכיוון הסגנוני של חוברת ההדגמה של
הגופן המסחרי "תחכמוני" (בית אלף), אבל **הוא אינו "תחכמוני"** ואינו מכיל את קווי המתאר שלו.
את "תחכמוני" עצמו, עם הווריאנטים, הניקוד הדינמי, אותיות הפתיח והאפשרויות המתקדמות שלו,
אפשר לרכוש מבית אלף. הגופן כאן הוא גרסה בסיסית ופשוטה יותר בהרבה.

## כיסוי תווים

* 27 האותיות העבריות (כולל סופיות) + הדיגרפים של היידיש װ ױ ײ
* ניקוד מלא: שווא, חטפים, חיריק, צירה, סגול, פתח, קמץ (וקמץ קטן), חולם, שורוק/קובוץ,
  דגש/מפיק, שין שמאלית וימנית, מתג, רפה — עם מיקום אוטומטי (GPOS)
* ספרות 0–9, פיסוק לטיני ועברי (מקף עברי ־, גרש ׳, גרשיים ״, סוף פסוק ׃, מירכאות, סוגריים, «»)
* רווחים, LRM/RLM/ZWJ/ZWNJ

**אין בגופן:** אותיות לטיניות (טקסט לועזי יוצג בגופן חלופי), טעמי מקרא, סימן ₪.

## התקנה

* **Windows:** פתחו את תיקיית `TTF`, סמנו את חמשת הקבצים, לחצן ימני ← **התקן** (או "התקן לכל המשתמשים").
* **macOS:** לחיצה כפולה על כל קובץ ← **התקן גופן** (Font Book). אפשר לסמן את כולם יחד.
* **Linux:** `mkdir -p ~/.local/share/fonts && cp TTF/*.ttf ~/.local/share/fonts/ && fc-cache -f`
* אחרי ההתקנה סגרו ופתחו מחדש את Word / InDesign / Illustrator כדי שהגופן יופיע ברשימה.
  בתפריט הגופנים יופיעו "Nusach" (או "נוסח" בממשק בעברית) ולצדו Light, Medium, Black.
* Google Docs אינו משתמש בגופנים מקומיים; ב-Canva אפשר להעלות את קבצי ה-TTF.

### שימוש באתר

```css
@font-face { font-family: "Nusach"; font-weight: 400; src: url("web/Nusach-Regular.woff2") format("woff2"); }
@font-face { font-family: "Nusach"; font-weight: 700; src: url("web/Nusach-Bold.woff2") format("woff2"); }
body { font-family: "Nusach", serif; direction: rtl; }
```

## בנייה מהמקור

כל אות מוגדרת כשלד קווים בקובץ `build/letters.py`, ונמשכת בקולמוס רחב וירטואלי.
משקל הוא פשוט גודל אחר של הקולמוס (`WEIGHTS` ב-`build/make_font.py`).

```bash
pip install fonttools shapely pillow brotli playwright
python3 build/make_font.py        # בונה את fonts/*.ttf
python3 build/check_fonts.py      # בדיקות תקינות
python3 build/specimen.py         # דף הדגמה
```
