# ספריית הגופנים (font-library)

ערכה שמאפשרת ל-Claude להכיר את כל הגופנים שלך ולבחור מביניהם לפי העניין — בצ'אט, בדסקטופ וב-Claude Code.

```
font-library/
  my-fonts/            ← זה ה-Skill עצמו (התיקייה שנארזת ונטענת)
    SKILL.md           ← הוראות הבחירה ל-Claude
    FONTS.md           ← קטלוג (נוצר אוטומטית)
    catalog.json       ← נתונים מלאים (נוצר אוטומטית)
    fonts/             ← כאן שמים את קבצי הגופנים
    scripts/           ← התקנה למערכת ויצירת @font-face
  notes.json           ← ההערות שלך על כל משפחה: קטגוריה, למה מתאים, ממה להימנע
  tools/               ← build_catalog.py · specimen.js · package_skill.py
```

## 1. הכנסת הגופנים

מעתיקים את הקבצים (`.ttf` / `.otf` / `.woff2`) לתוך `font-library/my-fonts/fonts/` (אפשר בתתי-תיקיות לפי משפחה), ודוחפים לריפו —
בהעלאה דרך אתר GitHub (Add file ← Upload files) או מהמחשב עם git.

## 2. בניית הקטלוג

```
pip install fonttools
python3 font-library/tools/build_catalog.py
```

הסקריפט קורא כל קובץ ומפיק: שם משפחה, משקלים, נטוי/משתנה, ותמיכה בעברית / ניקוד / טעמים / גרש-גרשיים-מקף-₪ / לטינית — כדי ש-Claude לא יבחר גופן שחסרות בו אותיות.

## 3. תצוגות מקדימות והערות

```
ONLY=hebrew MAXSTYLES=2 node font-library/tools/specimen.js   # תמונה לכל משפחה עברית; בלי ONLY — כל המשפחות
```

אפשר לבקש מ-Claude להסתכל על התמונות ולנסח את `notes.json` (קטגוריה / מתאים ל / להימנע), ואתה מתקן. אחרי עדכון ההערות מריצים שוב את שלב 2.

## 4. העלאה לצ'אט ולדסקטופ (Skill)

```
python3 font-library/tools/package_skill.py
```

נוצרים ב-`font-library/dist/` שני קבצי zip, כי הכול יחד גדול מדי: `my-fonts-hebrew.zip` (כל משפחה שיש בה עברית) ו-`my-fonts-latin.zip` (גופני אנגלית: טקסט, כותרות, כתב, כתב יד; גופני סמלים/סינית/אייקונים מושמטים ומודפסים ברשימה).
ב-claude.ai: **Settings ← Capabilities ← Skills ← Upload skill**, ומעלים כל zip בנפרד. (שמות התפריטים עשויים להשתנות.) אם אחד נדחה בשל גודל — מורידים משפחות או מפצלים עוד.

## 5. שימוש בריפו הזה (Claude Code)

בסשן על הריפו הזה Claude קורא את `FONTS.md` ישירות מהריפו (ראה `CLAUDE.md` בשורש) — אין צורך להעלות Skill.

## מגבלות שחשוב להכיר

- קבצי Word/PowerPoint שומרים רק את **שם** הגופן; מי שפותח אותם יראה אותם נכון רק אם הגופן מותקן אצלו. ל-PDF ולדפי HTML הגופן מוטמע ואין בעיה.
- אי אפשר לשנות את גופן הממשק של האפליקציה עצמה — רק את מה ש-Claude מייצר.
- **רישוי:** גופנים מסחריים מותר להטמיע ולהעלות רק לפי הרישיון שלהם. הריפו הזה כבר מתנהל כך: גופנים קנייניים של לקוח מופיעים ב-`.gitignore` ונשארים מקומיים בלבד. אם יש לך גופנים כאלה — לא לדחוף אותם לריפו ציבורי, ולהעלות אותם רק ל-Skill אישי (לא משותף). הריפו הזה מומלץ שיהיה פרטי.
