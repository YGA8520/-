# קונטרס חידושים – בונה, סותר, מכה בפטיש (מסכת שבת)

הפיכת כ־109 תמלולי שיעורים (חברותא בבית המדרש) לקונטרס חידושים. מבנה העבודה:

| שלב | מה נעשה | תוצר |
|---|---|---|
| 0 | תמלול שני בעזרת מודל עברי (`tools/colab_transcribe.ipynb`) ואיחוד מול תמלול "אלף בוט" | תמלול ממוזג עם סימון אי־הסכמות |
| 1 | ניקוי לשוני לכל הקלטה, תיקון מונחים, בדיקת ציטוטים מול ספריא | תמלול נקי |
| 2 | כרטיס מובנה לכל הקלטה: נושא, שאלה, דרכים, מסקנה, רמת ודאות, הפניה לדקה | כרטיסים |
| 3 | מפת נושאים לכל ההקלטות (סוגיות מפוזרות בין הקלטות) | מבנה הקונטרס |
| 4 | כתיבת הפרקים לפי `STYLE.md` | טיוטות |
| 5 | בקרה: השוואת כל משפט למקורו, ורשימת הוספות ואי־ודאויות | פרקים מאושרים |
| 6 | הרכבה ועימוד | קונטרס |

## פרטיות
הריפו ציבורי. התיקייה `private/` (תמלולים, מניפסט, שמע) **נמצאת ב־`.gitignore` ולא עולה לגיט**.

## קבצים
- `STYLE.md` – מדריך הסגנון וכללי היושרה.
- `tools/transcribe_ivrit.py` – תמלול רציף עם חידוש אוטומטי לאחר ניתוק (נבדק על קבצי שמע לדוגמה, כולל קובץ שבור, קובץ שקט ותיקיות משנה).
- `tools/colab_transcribe.ipynb` – מחברת Colab שמריצה את הסקריפט (נוצרת מהסקריפט באמצעות `tools/make_colab_notebook.py`).
